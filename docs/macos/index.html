Common questions

Does the app update tools automatically?

No. Update commands require exact approval and an explicit update action.

Does the cask include the CLI?

Yes. The cask installs the app and links its bundled CLI onto your Homebrew path.

Can I remove UpdateBar without deleting its data?

Yes. Uninstalling the cask does not automatically remove your local registry and logs.

Install the app and bundled CLI.

Use the signed Homebrew cask for the normal macOS setup.

$ brew install --cask sonim1/tap/updatebar-app
