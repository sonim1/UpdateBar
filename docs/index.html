Frequently asked questions

What does UpdateBar update?

It tracks Homebrew, npm, GitHub releases, files, and custom recipes that you add to its local registry.

Does UpdateBar run commands automatically?

No. Update commands run only after their exact command fingerprints have been explicitly approved.

Are approved commands sandboxed?

No. Approved commands run with your user privileges, an allowlisted environment, and time and output limits.

Does UpdateBar collect telemetry?

No telemetry is collected.

Can I use UpdateBar from the terminal?

Yes. The bundled CLI provides human output plus stable JSON and JSONL interfaces for scripts and external agents.
