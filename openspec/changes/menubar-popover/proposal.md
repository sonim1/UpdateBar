# Persistent menu bar popover

Replace the primary nested NSMenu with the approved compact native popover so users can select updates, review commands and follow results without losing context. Preserve the existing menu for secondary commands and the Dashboard for management.

This is a presentation change. Core command trust, update planning, cancellation/draining, CLI JSON/JSONL and exit codes remain compatible. Packaging stays the existing macOS 13+ SwiftPM app, with no additional dependencies.
